# Vue Toolkit example

Import `../vue-toolkit.goated` through **Settings → GOATed → Extensions → User → Add Extension…**. It contains one Vue skill, one prompt and a text reference, with no MCP suggestions or executable code.

The package contains only `extension.json`, `prompts/` and `skills/`. This README is outside the package format and is not included in the archive. Rebuild from this folder with:

```sh
zip -r ../vue-toolkit.goated extension.json prompts skills
```

The package guide is at `docs/wiki/GOATed-Packages.md` in the repository root. Import disabled to inspect it without changing future prompts. The example is not automatically installed by GOAT.
