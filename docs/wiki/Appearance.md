# Change appearance

GOAT follows system appearance by default. You can choose a theme and adjust reading preferences without changing project data or permissions.

## Choose a theme

Open **Settings → Appearance** and select System or a built-in theme. System follows the Mac’s light/dark setting; it is not a time-of-day schedule. Imported themes use the same underlying theme format.

## Adjust reading fonts

Choose the chat/composer and code fonts separately. The picker lists locally available fonts; selecting a font does not download it. Use the size controls and preview to check readability, then reset the preferences if needed.

Chat text supports 11–28 pt and code supports 10–24 pt. A missing saved font falls back to a system font while preserving the preference. Web preview documents own their own typography and may look different from the surrounding native interface.

## Resize the sidebar

In the 0.1.1 (Kid), drag the divider beside the chat sidebar to choose a width between 200 and 600 points. Its preferred starting width is 300 points. This wider range is not in 0.1.0 build 1343.

## Reset appearance and general preferences

In 0.1.1, **Settings → General → Manage → Reset preferences** lists the defaults and applies them immediately. It keeps your data, connections and permissions. See [Reset appearance and general preferences](../how-to/MANAGE-GOAT-DATA.md#reset-appearance-and-general-preferences) for the exact scope.

## Create a custom theme

Use the [theme-format reference](../THEMES.md) for folder layout, fields and font declarations. GOAT’s own theme artwork has separate [artwork terms](../../LICENSE-ART.md); the format, code and documentation are MIT-licensed.
