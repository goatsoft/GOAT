# Contribute to GOAT

Contributions can improve code, documentation, accessibility, examples and engine compatibility. Start with the [repository contributor guide](../../CONTRIBUTING.md), the canonical setup and review instructions.

Use the [architecture overview](Architecture.md) to find a module, the [extension example](Pronk-Example.md) for a small capability, and the [design reference](../DESIGN.md) for interface changes. Follow the [Code of Conduct](../../CODE_OF_CONDUCT.md). Report sensitive vulnerabilities through the [security policy](../../SECURITY.md), not a public issue.

Financial support helps sustain maintenance and development. The repository’s funding link identifies the selected provider; sponsorship does not establish a support contract or a feature entitlement.
